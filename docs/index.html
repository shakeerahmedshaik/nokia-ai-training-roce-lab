Distributed AI training over RoCEv2: the packet lab, end to end

Two PyTorch CPU workers train one MLP. Every step, their different local gradients are averaged by an NCCL-style ring AllReduce that moves as real RoCEv2 (Soft-RoCE rxe) across a 2-leaf / 2-spine SR Linux Clos (ixr-h5-64o, eBGP, 2-way ECMP). All numbers below come from the captures and counters in outputs/ of this repository.

worker1 rxe_w164rxe segments the WRITE into 4096 B packets, sets traffic class 0x6a (DSCP 26, ECT(0)), computes the ICRC, sends on eth1 (MTU 9000, offloads off)
leaf1 ethernet-1/10 in63Classifier ROCE maps DSCP 26 to fc3; ECMP hashes the 5-tuple (UDP sport differs per QP) to spine1 or spine2. Ingress discards happen here when rxe bursts faster than the software datapath

worker2 rxe_w2—Checks ICRC and PSN, places payload into the registered MR at RETH VA + offset, consumes a recv WQE on the immediate, returns ACK/NAK

Where the bytes go

RoCEv2 MB sent per rank vs the ideal

Ideal = 8.4 MB x 20 steps per rank. Source: UDP conversations above.

ECMP split: MB into each spine from each leaf

Spine interface counter deltas over Experiment B (outputs/expB-ecmp.txt). Only 341 MB of worker1's 513 MB reached the spines; the rest died at leaf1 ingress.

Lossy RoCE without PFC rxe sends each 2.1 MB stripe as fast as the veth allows, which exceeds the SR Linux software datapath (about 75 Mb/s per flow in ib_write_bw). leaf1 and leaf2 ethernet-1/10 discarded 38,402 and 36,270 frames during the run. Every drop causes a PSN gap, a NAK and a resend of everything after the gap.

Reproduce the captures

cd ai-training-lab
bash scripts/capture.sh start train          # tcpdump on worker1 eth1
bash run.sh train.py --steps 20 --features 1024 --hidden 2048 --wait
bash scripts/capture.sh stop train
bash scripts/analyze.sh captures/train.pcap  # totals, conversations, opcodes, DSCP/ECN/TTL, I/O graph
bash scripts/rxe-stats.sh                    # rxe retransmit and sequence-error counters
bash scripts/fabric.sh counters              # leaf discards, spine ECMP bytes

# useful tshark display filters
udp.dstport == 4791                 # all RoCEv2
infiniband.bth.opcode == 17         # RC ACK / NAK
infiniband.bth.destqp == 0x000022   # one QP
ip.dsfield.dscp == 26 && ip.dsfield.ecn == 3   # CE marks (none here)
